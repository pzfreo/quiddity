# TTT sheet-metal hanger input

`sm-hanger.step` is the geometry-only STEP export of the 23-02-02 SM Hanger
from the [build123d Too Tall Toby tutorial](https://build123d.readthedocs.io/en/latest/tttt.html).
The reference implementation is by Gumyr, copyright 2023, and published under
Apache-2.0 in that tutorial. Too Tall Toby supplied the original drawing to
build123d. The export was generated with build123d 0.11.0 and is retained here
for an offline, cross-platform recognition regression. It carries no names or
construction history.
