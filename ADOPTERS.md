# Who uses quiddity

Projects and organisations that use quiddity or haecceity. If you use either, please add
yourself: it helps others find working examples, and it helps us know what to keep stable.

**To add yourself,** open a pull request that adds one line to the table below, keeping it in
alphabetical order. If you'd rather not open a PR, [open an issue](https://github.com/pzfreo/quiddity/issues/new)
with the same details and we'll add it. Only list a project or organisation that has agreed
to be named.

| Project or organisation | Uses | What for |
|---|---|---|
| [draftwright](https://github.com/pzfreo/draftwright) | quiddity, haecceity | Technical drawings generated from STEP files |
| [specify-core](https://github.com/pzfreo/specify-core) | quiddity, haecceity | Interview-driven AP242 PMI authoring for STEP parts |
