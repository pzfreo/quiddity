Open-source Analysis Situs has five feature recognisers: drill holes, blends, cavities, convex hull and shafts. Its typed machining vocabulary (pockets, slots, steps by name) is in the commercial SDK and is not measured here.

Shafts

Turned shafts. MFInstSeg has none, so every claim is a false positive by the labels.

Shaft recognition claimed 2,898 faces in 2,517 models, and every one is the inner core of an O-ring groove — the same face quiddity reports as a boss. A reasonable reading of the geometry rather than noise. quiddity has no shaft family for prismatic parts; its turned_steps claimed nothing here.

  • On the median model quiddity is about level with all five Analysis Situs recognisers (72 vs 76 ms). On the mean Analysis Situs is faster, because quiddity has a long tail.
  • quiddity reads STEP about 4× faster (11 vs 49 ms). Analysis Situs's three feature recognisers take only 2.8 ms; convex hull is its one expensive step (27 ms).

How it was measured

  • Recognition: labelled feature instances with at least half their faces claimed. False negatives: instances with no face claimed. The same rule for both tools, since Analysis Situs reports face sets, not feature instances.
  • Claimed faces: labelled faces of the target classes that were claimed. False positives: claimed faces outside the target classes, as a share of all claimed faces.
  • quiddity is scored on each family's defining faces; consulted context (such as blind-hole floors) is not credited.
  • Body-level quiddity families (flats, plates, risers, step levels, stock, profiles, patterns, sheet metal, thin walls, turned steps) are excluded from feature claims.
  • Face-level only: dimensions and correct feature typing are not scored — where quiddity's advantage lies.
  • Analysis Situs calls: RecognizeDrillHoles (hard mode), RecognizeBlends (no radius cap), RecognizeCavities (no size or volume cap), RecognizeConvexHull (tolerance 0.1, 20-point grid — the Tcl command defaults), RecognizeShafts (no radius cap). Not included: probes, isolated features and canonical surfaces, which are not feature recognisers.
