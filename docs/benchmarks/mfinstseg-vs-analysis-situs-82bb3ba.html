MFInstSeg: quiddity and Analysis Situs measurements

The committed 0.4.8 results predate PRs #216 (flat floors and through-hole selector) and #217 (superseded groove records). They are historical, not measurements of current main. Analysis Situs was not rerun locally. Only the quiddity test split was rerun; the full-corpus results remain historical.

Recognition here means a labelled instance has at least half its faces in a tool's union of claimed faces, regardless of predicted instance identity. No-face instances have no face claimed. Claimed faces measures target-face recall; false positives are claims outside the target classes as a share of all claims. Dimensions and feature typing are not evaluated by this union metric.

These numbers are not comparable with mfinstseg_baseline.json. The repo scorer matches instances one to one at IoU ≥ 0.5; its any_feature excludes only step_levels and risers. This comparison's Any feature excludes twelve families: flats, freeform_surfaces, plates, risers, step_levels, thin_wall_bodies, sheet_metal_bodies, polygonal_stock, circular_face_patterns, repeating_radial_profiles, cylindrical_profiles, turned_steps.

Current scoring skips superseded_by records, retains source records, and selects class-1 holes with bottom == through; class 12 selects flat, drill_point or unknown bottoms. Pooled Holes takes their union. Analysis Situs's hole output is untyped and is used unchanged in both class rows. No O-ring faces are neutralized.

The historical quiddity Shafts row was invalid: it scored the union of all feature claims against an empty target. That row is removed because the raw sweep is unavailable. The current Shafts row uses only turned_steps as a proxy. MFInstSeg has no shaft target class, so this is a count of claims outside the target taxonomy, not evidence of geometric errors.

Timing scopes differ: quiddity measures calling-thread CPU; Analysis Situs measures process CPU, including any worker threads used by the STEP reader. Analysis Situs recognition includes AAG construction. Current quiddity recognition excludes JSON serialization; the historical example included serialization in its recognition interval. These are different workloads and clock scopes, not a controlled speed comparison.

Reproduction limits

This HTML is generated from committed aggregate JSON files. Historical raw sweeps are not committed, so the old scores cannot be reproduced from this branch. The full-corpus historical JSON used an earlier scorer. The October alpha.1 JSON is retained as an archival result with a different schema; no cross-run output-identity claim is made.

Fresh scores require the external MFInstSeg STEP and label files and raw tool sweeps. The README documents commands and the current run's provenance. The current test-split sweep is committed as tools/as_compare/runs/main-1b7dee67-test-qr.jsonl.gz (about 1 MB), with sweep, scorer and external-label digests in its aggregate JSON. Its records include 2,637 superseded holes and 2,637 superseded bosses; current scoring skips these records. Small synthetic scoring inputs and semantic tests are also committed.
