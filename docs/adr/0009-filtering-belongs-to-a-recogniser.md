# ADR 0009 — Filtering belongs to a recogniser, not a shared reduction

- **Status:** Superseded on 2026-09-15 by [ADR 0002](0002-uniform-deterministic-recogniser-contract.md)
- **Date:** 2026-08-19

The rule that a shared reduction is total over its input and that rejection is a recogniser's own
gate is now a paragraph of the recogniser contract. The measurement that motivated it (0% of
triangular pocket faces reaching any recogniser because a shared helper dropped oblique planes) is
in this file's git history.
